Tutorial Integrasi Knob Widget

Panduan lengkap untuk menyalin dan menggunakan widget knob di project lain

Persiapan Struktur File Instalasi Penggunaan Konfigurasi Contoh

1 Persiapan

File yang perlu disalin

Berikut adalah file-file yang perlu Anda salin ke project Anda:

widget_knob/knob.css

Stylesheet untuk tampilan widget

widget_knob/knob.js

JavaScript modular untuk animasi 3D

2 Struktur File

Struktur direktori yang direkomendasikan:

project/
├── asset/
│   └── widget_knob/
│       ├── knob.js      // Widget JavaScript
│       └── knob.css     // Widget Styles
├── your-project-files/
│   ├── main.js
│   └── main.css
├── index.html
└── tutorial.html  // Opsional: dokumentasi

3 Instalasi

Langkah 1: Include Three.js

Tambahkan import map untuk Three.js di dalam tag <head>:

<!-- Import Map untuk Three.js -->
<script type="importmap">
    {
        "imports": {
            "three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js",
            "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/"
        }
    }
</script>

Langkah 2: Include Widget Files

Tambahkan CSS dan JS widget:

<!-- Widget CSS -->
<link rel="stylesheet" href="asset/widget_knob/knob.css">

<!-- Widget JavaScript -->
<script type="module" src="asset/widget_knob/knob.js"></script>

4 Penggunaan Dasar

1. Buat HTML Container

<!-- Container utama harus memiliki class "knob-widget" -->
<div id="my-knob-container" class="knob-widget knob-panel">
    <!-- Output display -->
    <div class="knob-output-display">
        <span id="color-output">#00FFFF</span>
    </div>
</div>

2. Inisialisasi JavaScript

// Inisialisasi knob widget
const knob = KnobWidget.init('#my-knob-container', {
    defaultTheme: 'gelap',
    outputCallback: (hexColor, colorObject) => {
        console.log('Warna dipilih:', hexColor);
        // Gunakan hexColor untuk keperluan Anda
        document.getElementById('color-output').textContent = hexColor;
    }
});

5 Opsi Konfigurasi

Opsi Tipe Default Deskripsi
defaultTheme string 'gelap' Tema default saat inisialisasi
outputCallback function null Callback saat warna berubah
onThemeChange function null Callback saat tema berubah
onAngleChange function null Callback saat angle berubah

Tema yang Tersedia

gelap

Dark Matte - Tema default dengan efek gelap matte

glow

Neon Glow - Tema dengan efek neon glow

gloomy

Titanium - Tema titanium metalik

cerah

Pure Silver - Tema silver cerah

// file: your-app.js

// Inisialisasi KnobWidget
document.addEventListener('DOMContentLoaded', () => {
    const knob = KnobWidget.init('#knob-container', {
        defaultTheme: 'gelap',

        // Callback saat warna berubah
        outputCallback: (hexColor, colorObject) => {
            // hexColor: '#00FFFF'
            // colorObject: THREE.Color object

            // Update UI Anda di sini
            const outputEl = document.getElementById('color-output');
            if (outputEl) {
                outputEl.textContent = hexColor;
                outputEl.style.color = hexColor;
            }

            // Atau gunakan colorObject untuk keperluan lain
            console.log(`R: ${colorObject.r}, G: ${colorObject.g}, B: ${colorObject.b}`);
        },

        // Callback saat tema berubah
        onThemeChange: (themeName) => {
            console.log('Tema berubah ke:', themeName);
        },

        // Callback saat angle berubah
        onAngleChange: (angle) => {
            // angle dalam radian
        }
    });

    // API untuk mengontrol knob
    knob.setTheme('glow');           // Ganti tema
    knob.setCameraLocked(false);     // Bebaskan/ kunci kamera
    const value = knob.getValue();   // Dapatkan nilai 0-360

    // Mengakses instance yang sudah ada
    const existingKnob = KnobWidget.getInstance('#knob-container');
    if (existingKnob) {
        existingKnob.setTheme('cerah');
    }
});

7 API Reference

KnobWidget.init(container, config)

Inisialisasi knob widget baru.

Parameter:
  container: string | HTMLElement  - Selector atau element
  config: Object                    - Konfigurasi opsional

Returns: KnobInstance

KnobInstance.setTheme(themeName)

Ganti tema widget.

themeName: 'gelap' | 'glow' | 'gloomy' | 'cerah'

KnobInstance.getValue()

Dapatkan nilai knob (0-360).

Returns: number (0-360)

KnobInstance.setCameraLocked(locked)

Kunci atau bebaskan kamera 3D.

locked: boolean - true untuk kunci, false untuk bebas

KnobInstance.destroy()

Hapus instance dan bersihkan resource.
